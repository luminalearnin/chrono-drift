# CHRONO-DRIFT

A self-contained neon arcade roguelike built with one `index.html`: HTML5 Canvas rendering, vanilla JavaScript, and Web Audio API sound.

## How to play

- **Move:** WASD or arrow keys (touch stick on phones)
- **Drift:** Space (touch DRIFT button)
- **Fire:** X / Enter (touch FIRE button)
- **Pause:** P
- Collect green Time Shards to add 1.5 seconds.
- Drift to build Slingshot charge, then release drift to boost.
- Activate both switches; an Echo can hold switches while you enter the vault.
- Complete four 30-second Loops. Your recorded runs become translucent Echo teammates.
- Press **S** in the title screen for the sidegrade garage and **L** for the lore log.

Progression is stored locally in `localStorage`; no external assets or libraries are required.
